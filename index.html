🔧 Comment on construit un moteur fou ?

  • 1. Fais glisser une source d’énergie ⚡ dans le capot (ou tape dessus pour la poser).
  • 2. Ajoute un moteur ⚙️ au milieu, puis un équipement 🎁 sur le toit.
  • 3. Appuie sur 🚀 ESSAYER et regarde la voiture rouler sur la piste.
  • Tape une pièce déjà posée pour l’enlever. Le but : aller le plus loin, pas le plus vite !

🌍 Le petit plus

Chaque carte donne une vraie information. L’essence roule bien mais salit l’air, le solaire est propre mais faible… Les meilleurs mécano·es trouvent le compromis ! Les ⭐ montrent les pièces qui s’entendent bien ensemble.
