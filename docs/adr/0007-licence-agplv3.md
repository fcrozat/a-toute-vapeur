# Licence : AGPLv3

Le projet est publié sous **GNU AGPLv3** : le jeu est un objet pédagogique qu'on veut libre et réutilisable, et ses dérivés doivent le rester. Les alternatives ouvertes étaient MIT ou CC0 — plus permissives, mais elles laissent quelqu'un d'autre refermer le jeu dans un produit fermé, ce que nous ne voulons pas pour un objet qui explique comment marche une machine.

## Consequences

L'AGPL ajoute à la GPLv3 l'obligation, pour un programme accessible par réseau, d'offrir le code source à qui s'en sert à distance (clause 13). Cela veut dire concrètement : **tant que le dépôt est privé, le jeu ne peut pas être hébergé** sous cette licence. Publier sur GitHub Pages ou itch.io suppose donc de rendre le dépôt public, ou de trouver un hébergement qui redistribue la source — l'issue #1 porte déjà ce nœud.

Le jeu n'a aucune dépendance à l'exécution, ce qui écarte la plupart des soucis de compatibilité. Reste à trancher la licence des dessins et des textes ; la direction retenue est un copyleft aussi pour le contenu, pour ne pas mélanger deux régimes sur un même objet.
